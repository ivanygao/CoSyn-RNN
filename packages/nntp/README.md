# Neural Network Training Pipeline

This directory contains the source code for the `nntp` package. The package must be installed in your local Python environment before it can be used.

From the repository root, run:

```bash
pip install -e ./packages/nntp
```

Alternatively, from this directory, run:

```bash
pip install -e .
```

The `-e` option installs the package in editable mode, so changes to the source code take effect without reinstalling the package.
