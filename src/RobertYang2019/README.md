## Bundled Robert Yang 2019 Task Definitions

This repository includes a local copy of the Robert Yang 2019 task-generation implementation in `RobertYang2019.py`. The file is bundled so that the NNTP pipeline can provide a default set of cognitive tasks without requiring the original repository as an external dependency.

`RobertYang2019.py` is derived from the task implementation associated with Robert Yang et al. (2019), originally available from the [`gyyang/multitask`](https://github.com/gyyang/multitask) repository. It is not an original contribution of this project.

The surrounding NNTP dataset interface, dataset management code, pipeline integration, and other project components were implemented separately for this repository.

See [`RobertYang2019.md`](./RobertYang2019.md) for the original source, citation, licensing information, and a description of the modifications made to `RobertYang2019.py`.

## Reference

Yang, Guangyu Robert, et al. “Task Representations in Neural Networks Trained to Perform Many Cognitive Tasks.” *Nature Neuroscience*, vol. 22, no. 2, 2019, pp. 297–306.
